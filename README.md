# Journal d'Entraînement

Application web style calendrier pour noter vos entraînements au jour le jour.

## Fonctionnalités

- Vue calendrier mensuelle (navigation facile)
- Clic sur un jour pour enregistrer :
  - Exercices de force : Pompes, Dips, Tractions, Abdos + exercices personnalisés (nom + reps)
  - Course à pied : distance (km), temps (minutes), allure moyenne calculée automatiquement
  - Notes libres
- Indicateur visuel sur les jours avec données
- Statistiques du mois (jours d'entraînement, km, pompes...)
- Sauvegarde 100% locale (localStorage) — aucune donnée envoyée en ligne
- Export / Import JSON pour sauvegarde ou transfert

## Utilisation

Ouvrez simplement `index.html` dans votre navigateur (ou hébergez-le sur GitHub Pages / Netlify).

Les données restent sur votre appareil.

## Hébergement

Ce repo est prêt pour GitHub Pages : activez Pages sur la branche main, dossier racine.
